BRASA & MESA - Web demo

Abrir en Visual Studio Code:
1. Descomprime la carpeta.
2. Archivo > Abrir carpeta > brasa-y-mesa.
3. Opcional: instala la extension Live Server y haz clic en Go Live (abajo a la derecha).
   Tambien puedes abrir index.html directamente en el navegador.

Archivos:
- index.html  estructura
- css/styles.css  estilos
- js/main.js  menu, pedido y reservas

Nota: las fuentes (Manrope) cargan desde Google Fonts, necesitas internet.
